# Статусы кампаний RuSender

## Два независимых поля
`status` — жизненный цикл рассылки. `statusModerate` — вердикт модерации. Меняются отдельно,
и одно и то же слово `banned` в них означает разное.

### `status`
| Значение | Смысл | Архивируется |
|---|---|---|
| `draft` | черновик, не запускался | нет (только удаление) |
| `built` | собрана, готова к запуску | нет |
| `scheduled` | запланирована на время | нет |
| `in_progress` | идёт отправка | нет |
| `paused` | отправка приостановлена | нет |
| `completed` | завершена | **да** |
| `banned` | заблокирована системой (спам, жалобы), как правило уже после старта | **да** |
| `on_hold` | придержана системой | нет |

### `statusModerate`
| Значение | Смысл |
|---|---|
| `not_ready_to_moderate` | на модерацию не отправлялась (обычный черновик) |
| `moderating` | на модерации |
| `approved` | одобрена |
| `banned` | **отклонена модератором** |

## Типичные сочетания
- `completed` + `approved` — нормальная отправленная рассылка.
- `completed` + `banned` — модератор завернул; письма не уходили, но статус жизненного цикла
  всё равно «завершена». Именно это ищут, когда просят «отклонённые на модерации».
- `banned` + `approved` — модерацию прошла, но систему что-то не устроило при отправке.
  Это НЕ отклонение модерации.
- `draft` + `not_ready_to_moderate` — черновик.

## Фильтрация в API
- `campaigns_list(status: [...])` — фильтр есть, принимает массив.
- `statusModerate` — **фильтра нет**, только полный перебор страниц.
- `campaigns_list(archived: true)` — показать архив; по умолчанию архив скрыт.
- `campaigns_list(name: "подстрока")` — поиск по названию.

## Ограничения архива и удаления
- `campaigns_archive` — только `completed` и `banned`; у составных архивируется вся семья.
- `campaigns_unarchive` — возвращает обратно, операция обратима.
- `campaigns_delete` — только черновики, необратимо, **удаляет и шаблон кампании**.
