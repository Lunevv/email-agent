# RuSender: агент по нескольким проектам

**Версия:** 1.0.0 · **Лицензия:** MIT · Требует подключённого MCP-коннектора
[RuSender](https://rusender.ru/features/email/mcp/)

Даёт агенту долгую память по проектам. Один аккаунт RuSender часто обслуживает не один продукт, а
десяток: у каждого свой отправитель, своя база, свой тон и свои запреты. Навык заводит реестр
проектов, опознаёт по задаче, о каком из них речь, поднимает его контекст и разворачивает в конкретные
параметры кампании — чтобы не объяснять одно и то же в каждом новом диалоге.

Сам рассылки не создаёт и не запускает: его работа — опознать проект и передать дальше.

## Установка

```bash
cp -r rusender-agent ~/.claude/skills/      # Claude Code, личные навыки
cp -r rusender-agent .claude/skills/        # Claude Code, навыки проекта
```

Для claude.ai запакуйте папку в ZIP и загрузите в `Settings → Capabilities → Skills`.

## Что нужно рядом

| Навык | Зачем |
|---|---|
| `rusender-campaign-create` | Создание черновика, куда агент передаёт контекст проекта |
| `rusender-preflight` | Проверка черновика сразу после создания |
| `rusender-results` | Сбор статистики и наполнение истории проекта |

Без них навык работает, но короче: опознает проект и развернёт параметры, а дальше скажет, чего не
хватает.

## Как вызвать

Срабатывает сам:

```
Подготовь рассылку для uKit, вот текст. Возьми наш стандартный шаблон.
Какие у нас проекты?
Заведи проекты по моему аккаунту.
Что мы слали по uCoz за последний месяц?
```

Явно — `/rusender-agent`.

## Память

Файлы лежат в `.rusender-agent/` в рабочей папке: профили проектов, история кампаний, гипотезы.
Персональных данных подписчиков там нет и быть не должно — только агрегаты уровня кампании.

В комплекте с агентом идут двенадцать демо-проектов — в папке `projects/` его репозитория. У
каждого свой контекст, история рассылок, метаданные списков и лог, так что видны и проверка
пересечений, и сравнение результата с прошлыми рассылками.

Если установлен только этот навык, без репозитория, — образец формата профиля лежит в
`references/profile-example.md`.

**В claude.ai файлов нет**, поэтому память между диалогами не сохранится — опознание проекта и
разворачивание параметров работают, остальное нет.
