# RuSender: результаты рассылки и сравнение с историей

**Версия:** 1.0.0 · **Лицензия:** MIT · Требует подключённого MCP-коннектора
[RuSender](https://rusender.ru/features/email/mcp/)

Забирает статистику отправленной рассылки, записывает её в историю проекта и сравнивает с
предыдущими кампаниями этого же проекта. Отвечает не «OR 34%», а «OR 34,2% против медианы 29,8% по
десяти сопоставимым рассылкам» — потому что само по себе число почти ничего не значит.

Отделяет факты от наблюдений и гипотез, ведёт список гипотез по проекту и проверяет ранее открытые.

Для визуального дашборда по одной кампании есть отдельный навык `rusender-campaign-report`,
по A/B-тесту — `rusender-ab-report`. Здесь текст, история и сравнение.

## Установка

```bash
cp -r rusender-results ~/.claude/skills/      # Claude Code, личные навыки
cp -r rusender-results .claude/skills/        # Claude Code, навыки проекта
```

Для claude.ai запакуйте папку в ZIP и загрузите в `Settings → Capabilities → Skills`.

## Как вызвать

```
Собери статистику по рассылке 116840.
Как отработало последнее письмо по uCoz? Сравни с прошлыми.
Обнови цифры по вчерашней рассылке.
```

Явно — `/rusender-results`.

## Память

Историю навык пишет в `.rusender-agent/projects/<slug>/history.jsonl`, гипотезы — в `notes.md` рядом.
Формат общий с навыком `rusender-agent`; если тот не установлен, история всё равно ведётся, просто
проект придётся называть самому.

Ключ записи — `campaign_id`: повторный сбор перезаписывает строку, а не добавляет новую. Статистика
дозревает неделями, и «обнови цифры» — штатный сценарий.

Персональных данных подписчиков в истории нет — только агрегаты уровня кампании.
