**Jira import is out of beta.** It moves issues, statuses, comments and attachments. Issue links
are not migrated yet — we are working on it. You can start it from workspace settings; it takes a
few minutes for small projects and up to half an hour for large ones. Everything imported lands in
a separate project, so existing work is untouched.

**New roles.** You can now give someone view access without edit rights. Useful for clients and
contractors who need to follow progress but should not move cards around.

**Smaller sidebar.** It collapses to icons and remembers the state per workspace.

No breaking changes in this release.
